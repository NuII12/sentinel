    What this page can’t do

    It runs without a server, so it can’t look up CVEs or run server-side scans. Breach, DNS and domain lookups call public services directly, which works on a host such as GitHub Pages but not in the hosted preview. Those modules are listed with their requirements under Modules. No exposure score is shown, because there is no breach data to base one on.

    Password checker

    Analysis runs in your browser. Passwords are never stored or logged.

      What leaves your browser

      Pressing “Check known breaches” computes a SHA-1 hash locally and sends only its first 5 characters to Have I Been Pwned. The service returns all matching suffixes and your browser compares them. The full password and full hash are never sent. Reuse checks compare hashes in memory for this tab only.

      URL analyzer

      Looks for warning signs in the address itself. The link is never opened or requested.

      These are heuristics, not a reputation lookup. Redirects, domain age and blocklists need a server and API keys (see Modules).

      FileTrust

      Calculates a file’s SHA-256 in your browser. The file is not uploaded.

      Privacy

      What this page can read from your browser right now.

      Suggestions

        What a web page can’t see

        Your extensions, the trackers loaded on other sites, third-party cookies set elsewhere, your DNS provider or VPN, and most browser settings. Check those in your browser’s own privacy settings.

        Password generator

        Uses your browser’s secure random number generator. Nothing is sent or saved.

        Open checker

        Use a different generated password for every account and keep them in a password manager.

        Domain checker

        Looks up a domain’s DNS records and registration data. Only the domain name is sent, to Cloudflare’s public DNS service and to rdap.org.

        A young domain isn’t proof of fraud, and an old one isn’t proof of safety. Use this together with the URL analyzer.

        Email security

        Checks whether a domain publishes SPF, DKIM, DMARC and MTA-STS records, which make it harder to forge mail from that domain.

        DKIM keys are published under a selector name the domain chooses. This page tries nine common ones, so “not found” doesn’t prove DKIM is missing.

        Email breaches

        Checks an email address against known breaches through your own Worker. It uses the free XposedOrNot service, or Have I Been Pwned if you add a key to the Worker.

        Watchlist

        Addresses are saved in this browser only and checked when you press the button. This page can’t watch in the background or send alerts.

        Worker address

        The address of the Worker you deployed from worker.js. The email address goes to your Worker and on to XposedOrNot, or to Have I Been Pwned if you added a key.

        Website scanner

        Reads a site’s security headers through your Worker. Passive only: one ordinary request, nothing probed.

        Worker address

        The same Worker as on the Email breaches page.

        Vulnerabilities

        Flaws that attackers are known to exploit, from the CISA catalogue. Kept up to date by your refresh workflow.

        Breach timeline

        Publicly known data breaches, newest first, from the Have I Been Pwned list.

        Exposure map

        Which kinds of personal data leak most often across known breaches.

        This describes breaches in general, not you. A personal exposure score needs verified results for your own accounts, so none is shown.

    What this page can’t do

    It runs without a server, so it can’t look up breaches, CVEs, DNS or domain data. Those modules are listed with their requirements under Modules. No exposure score is shown, because there is no breach data to base one on.

    Password checker

    Analysis runs in your browser. Passwords are never stored or logged.

      What leaves your browser

      Pressing “Check known breaches” computes a SHA-1 hash locally and sends only its first 5 characters to Have I Been Pwned. The service returns all matching suffixes and your browser compares them. The full password and full hash are never sent. Reuse checks compare hashes in memory for this tab only.

      URL analyzer

      Looks for warning signs in the address itself. The link is never opened or requested.

      These are heuristics, not a reputation lookup. Redirects, domain age and blocklists need a server and API keys (see Modules).

      FileTrust

      Calculates a file’s SHA-256 in your browser. The file is not uploaded.

      Suggestions

        What a web page can’t see

        Your extensions, the trackers loaded on other sites, third-party cookies set elsewhere, your DNS provider or VPN, and most browser settings. Check those in your browser’s own privacy settings.

        Password generator

        Uses your browser’s secure random number generator. Nothing is sent or saved.

        Open checker

        Use a different generated password for every account and keep them in a password manager.
